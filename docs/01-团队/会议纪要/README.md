# 会议纪要

## 命名规则

`YYYY-Www-会议类型.md`，例如 `2026-W43-Sprint0计划会.md`、`2026-W44-每日站会.md`。

## 存放要求

- 每次会议结束后 24 小时内归档到本目录；
- 纪要必须包含：时间、地点/链接、参与人、主持、记录、议程、决议表、行动项表、下次会议；
- 行动项必须有负责人、截止、验收方式、状态。
