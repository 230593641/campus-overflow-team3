# 用户访谈纪要

## 访谈1：大二学生（小明，计科2412）

**时间**：2026-10-25
**方式**：微信语音

**问题与回答**：

1. 你平时做作业遇到不会的怎么办？
   > 先搜百度，找不到就问室友，室友也不会就去课程群里问。但群里问挺尴尬的，怕老师觉得我连这都不会。

2. 你觉得课程群答疑有什么问题？
   > 消息刷太快了，昨天问的问题今天就找不到了。而且重复的问题很多，老师每周要答一样的东西。

3. 如果有个专门的问答平台，你希望有什么功能？
   > 能匿名提问就好了。然后有人回答了能通知我。最好能看到"老师已认证"的回答，那是标准答案。

4. 你愿意给回答问题的人奖励吗？
   > 悬赏的话，用课程积分什么的就行，不用真钱。我采纳了别人的回答，给人加几分我也乐意。

**关键洞察**：匿名提问是刚需；需要通知机制；教师认证的回答最有价值。

## 访谈2：助教（李姐，研一计科）

**时间**：2026-10-25
**方式**：当面

**问题与回答**：

1. 你每周答疑的工作量多大？
   > 80个学生，每周大概20-30个问题，其中60%是重复的。我把高频问题整理成FAQ发群里，但还是有人问。

2. 你希望平台帮你解决什么？
   > 学生能互相答最好，我只需要看一眼、采纳或者认证。如果有人答得好，我给个"教师认证"标记，其他学生就能看到。

3. 你觉得什么样的回答是好回答？
   > 简洁、有代码示例、能跑通。长篇大论反而没人看。

**关键洞察**：教师认证是核心功能；学生互答能大幅减轻助教负担。

## 访谈3：大三学长（王哥，计科2311）

**时间**：2026-10-25
**方式**：微信

**问题与回答**：

1. 你愿意在课程平台上答疑吗？
   > 可以啊，反正我那门课学过。但如果只是免费回答，时间长了就没动力了。

2. 什么能激励你持续答疑？
   > 排名吧，每周答疑最多的人排第一，有点成就感。或者给个徽章，比如"数据结构百答"什么的。

3. 你觉得悬赏功能怎么样？
   > 好啊，有人悬赏的题我优先答，说明他真的急。但悬赏别用真钱，用课程积分就行。

**关键洞察**：排行榜和徽章是持续激励；悬赏能帮用户快速找到愿意答的人。
