# 产品愿景与用户画像

## 产品愿景

CampusOverflow 是一个面向高校课程的校园问答平台，让学生在遇到课程问题时能快速找到答案、互相解答，教师能高效管理课程内容和学生互动。

**一句话**：像 StackOverflow，但专门服务于一门课的学生。

## 目标用户

| 角色 | 描述 | 核心诉求 |
|---|---|---|
| **选课学生** | 修这门课的本科生，大二大三为主 | 作业不会做、概念搞不懂、复习找重点 |
| **课程教师** | 授课教师或助教 | 答疑减负、了解学生薄弱点、筛选优质回答 |
| **热心学长** | 上过这门课的高年级学生 | 帮学弟学妹、攒声誉 |

## 核心用户画像

### 画像1：焦虑的大二学生（小明）
- 大二计科，正在学数据结构
- 作业写到跳表部分卡了2小时
- 想在课程群里问，但怕被同学觉得菜
- 希望：匿名提问、有人快速回答、能看到往届类似问题

### 画像2：忙碌的助教（李姐）
- 研一，带2个班共80人
- 每周收到20+重复问题，答不过来
- 希望：优质回答被点赞顶上来、重复问题能合并、悬赏功能激励学生互答

### 画像3：乐于助人的学长（王哥）
- 大三，上过这门课95分
- 课余时间多，愿意答疑
- 希望：答疑有成就感（徽章/排名）、能被学弟学妹记住

## 核心场景

1. **小明提问**："跳表和红黑树的区别是什么？" → 标签数据结构 → 被3个同学回答 → 李姐采纳最佳答案
2. **小明悬赏**："这道作业题有人会吗？悬赏50学分" → 王哥回答 → 小明采纳 → 王哥+15声誉
3. **期末考试前**：小明搜"排序算法" → 看到往届高频问题汇总 → 复习效率提升
