# 用户故事地图与 Product Backlog

## 用户故事地图

### 主线（用户旅程）

**发现问题 → 提问 → 等待回答 → 收到回答 → 采纳/投票 → 复习/搜索**

### 用户活动分解

| 用户活动 | 用户任务 | 优先级 |
|---|---|---|
| **注册登录** | 用学校账号注册、加入课程 | P0 |
| **提问** | 写问题、加标签、可选悬赏 | P0 |
| **回答** | 写回答、一层回复、投票 | P0 |
| **管理内容** | 编辑/删除自己的问题或回答 | P0 |
| **采纳** | 提问者或教师采纳最佳答案 | P0 |
| **通知** | 有人回答/采纳/提到我时通知 | P0 |
| **搜索发现** | 关键词搜索、相关问题推荐 | P1 |
| **声誉激励** | 排行榜、徽章、悬赏结算 | P1 |
| **教师管理** | 教师认证、删除不当内容 | P0 |

---

## Product Backlog（按Sprint分组）

### S0（已完成中）
- 团队组建、仓库、CI、环境验证
- 团队章程、自我介绍、架构笔记

### S1（Identity 增量，选2个）
- [T-S1-01] 选课审批：学生申请加入课程，教师审批
- [T-S1-02] 个人资料编辑：修改昵称、头像
- [T-S1-03] 课程成员管理：教师查看/移除成员

### S2（Q&A 问答核心）
- [T-S2-01] 提问：标题+正文+标签
- [T-S2-02] 回答：写回答、一层回复
- [T-S2-03] 投票：赞/踩、改投、撤销
- [T-S2-04] 编辑/删除：作者可编辑自己的，教师可删除
- [T-S2-05] 采纳最佳答案
- [T-S2-06] 教师认证回答
- [T-S2-07] 问题列表：按最新/热门/未回答排序
- [T-S2-08] 问题详情页

### S3（声誉+发现）
- [T-S3-R01] 声誉账本：赞+10、踩-2、日上限200
- [T-S3-R02] 徽章：初露锋芒等
- [T-S3-R03] 悬赏：发起/冻结/结算/到期退款
- [T-S3-R04] 排行榜：周/月/学期
- [T-S3-D01] 中文搜索
- [T-S3-D02] 相关问题推荐
- [T-S3-D03] 通知中心
- [T-S3-D04] @提醒

### S4（发布）
- 可观测性、部署、答辩
