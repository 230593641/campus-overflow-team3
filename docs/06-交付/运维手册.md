## 常见故障处置

| 故障 | 现象 | 处置 |
| --- | --- | --- |
| 数据库连不上 | 后端启动报连接超时 | 【待填】检查 mysql 容器、账号密码、3306 |
| 镜像拉取失败 | compose 拉取超时 | 【待填】换国内镜像源、提前拉取 |
| 502 | 网关返回 Bad Gateway | 【待填】后端是否就绪、nginx upstream |
| 磁盘满 | 容器异常退出、写入失败 | 【待填】清理日志/无用镜像 |
