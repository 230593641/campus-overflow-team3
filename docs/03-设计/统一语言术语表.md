# 统一语言术语表（Ubiquitous Language）

> 列：中文 | English | 定义 | 所属上下文 | 禁用说法。开发、文档、测试命名统一使用左列术语。

| 中文 | English | 定义 | 上下文 | 禁用说法 |
| --- | --- | --- | --- | --- |
| 问题 | Question | 用户发起的求助帖，含标题、正文、标签 | Q&A | 帖子、主题 |
| 回答 | Answer | 针对某个问题提交的解决方案 | Q&A | 回复、评论 |
| 采纳 | Accept | 提问者标记某个回答对自己有帮助 | Q&A | 结帖、选中 |
| 投票 | Vote | 对问题或回答的赞成/反对 | Q&A | 点赞、打分 |
| 赞成票 | Upvote | 票值 +1 的投票 | Q&A | 顶、喜欢 |
| 反对票 | Downvote | 票值 -1 的投票 | Q&A | 踩、讨厌 |
| 改票 | Revote | 修改自己已投的票，按新旧效果差结算 | Q&A | 取消赞 |
| 标签 | Tag | 问题的分类标记，1-5 个 | Q&A | 分类、关键字 |
| 评论 | Comment | 对帖子的澄清性短文本，不产生声誉 | Q&A | 回复、留言 |
| 背书 | Endorse | 课程管理者对回答的一次权威认可 | Q&A | 推荐、置顶 |
| 软删除 | Soft Delete | 标记删除而非物理移除，可追溯 | 跨层 | 删掉、清空 |
| 声誉 | Reputation | 用户贡献的累计分值 | Reputation | 积分、等级 |
| 声誉账本 | Reputation Ledger | 逐条记录加分/扣分流水 | Reputation | 余额表、分数表 |
| 冻结 | Freeze | 锁定待结算的声誉分值，不可直接动用 | Reputation | 锁住、冻结积分 |
| 扣减 | Spend | 从冻结额度支出声誉 | Reputation | 花掉、扣除 |
| 退还 | Refund | 结算失败时把冻结分值退回 | Reputation | 还回来 |
| 每日上限 | Daily Cap | 单日正向投票收益的封顶值 | Reputation | 每日限制 |
| 徽章 | Badge | 达到阈值后授予的成就标记 | Reputation | 勋章、称号 |
| 悬赏 | Bounty | 用声誉悬赏特定问题 | Reputation | 打赏、奖励 |
| 结算 | Settle | 悬赏采纳后把声誉支付给回答者 | Reputation | 结账、发奖 |
| 排行榜 | Leaderboard | 按声誉排序的贡献者榜单 | Reputation | 排名榜、富豪榜 |
| 对账 | Reconciliation | 核对账本与事件，保证守恒无重复 | Reputation | 盘点、查账 |
| 通知 | Notification | 回答、采纳、@ 等事件的提醒 | Discovery | 消息、推送 |
| 已读 | Mark Read | 标记通知已查看 | Discovery | 看过了 |
| 搜索 | Search | 按关键词检索问题与回答 | Discovery | 查找、搜一下 |
| 全文检索 | Full-text Search | 基于分词索引的中文匹配 | Discovery | 全文搜索（可用，避免"模糊查询"） |
| 相关推荐 | Related Recommendation | 基于相似度推荐相似问题 | Discovery | 猜你喜欢 |
| 杰卡德相似度 | Jaccard Similarity | 标签/词项交集除以并集的相似度 | Discovery | 重合度 |
| @提及 | Mention | 回答/正文里引用某人 | Discovery | @一下、提醒 |
| 领域事件 | Domain Event | 领域内已发生事实的记录，用于跨上下文通知 | 跨层 | 消息、回调 |
| 事务性发件箱 | Transactional Outbox | 先落库事件再异步投递的可靠模式 | 跨层 | 发件箱表 |
| 限界上下文 | Bounded Context | 一套统一语言与模型的边界 | 架构 | 模块、系统 |
| 聚合 | Aggregate | 一致性边界内的领域对象集合 | 架构 | 实体组 |
| 聚合根 | Aggregate Root | 聚合对外的唯一入口 | 架构 | 主实体 |
| 值对象 | Value Object | 无身份、以属性相等判断的对象 | 架构 | 附属实体 |
| Walking Skeleton | Walking Skeleton | 贯穿主链路的最小可运行切片 | 架构 | 骨架 demo |
| DoD | Definition of Done | 任务完成的统一标准 | 团队 | 验收标准（狭义可用） |
| PR | Pull Request | 合并前的评审请求 | 协作 | 合并申请 |
