# 聚合清单

> 列：上下文 | 聚合根 | 内部实体/值对象 | 关键不变式 | 对应代码文件。代码路径为相对 backend 的参考位置，实现时以测试规格为准。

| 上下文 | 聚合根 | 内部实体/值对象 | 关键不变式 | 对应代码文件 |
| --- | --- | --- | --- | --- |
| Identity | User | 角色、会话 | 一人一账号；角色枚举合法；密码不落明文 | `co-identity/co-identity-domain/.../User.java`（参考实现） |
| Identity | Course | 成员、角色分配 | 仅课程管理者可创建/管理；成员归属唯一课程 | `co-identity/co-identity-domain/.../Course.java`（参考实现） |
| Q&A | Question | MarkdownBody、Tags | 标题 10-150 字；标签 1-5 个；关闭后不接受新回答；仅作者或课程管理者可编辑/删除；已采纳答案不能被删除 | `co-qa/co-qa-domain/.../Question.java` |
| Q&A | Answer | MarkdownBody | 仅课程管理者可背书且只能一次；被采纳的回答不能由作者删除 | `co-qa/co-qa-domain/.../Answer.java` |
| Q&A | Vote | 票值 | 不能给自己的内容投票；票值只能是 +1/-1；改票按"新效果-旧效果"计算增量 | `co-qa/co-qa-domain/.../Vote.java` |
| Q&A | Comment | — | 澄清性短文本，不产生声誉；依附于问题或回答 | `co-qa/co-qa-domain/.../Comment.java` |
| Reputation | ReputationAccount | 账本条目 | 冻结-扣减-退还必须守恒；每日上限只限制正向投票收益 | `co-reputation/co-reputation-domain/.../ReputationAccount.java` |
| Reputation | Bounty | 悬赏条目 | 仅课程管理者可在限额内发起；赞助者不能赢自己的悬赏；只能结算一次 | `co-reputation/co-reputation-domain/.../Bounty.java` |
| Reputation | BadgePolicy | 徽章定义 | 达到阈值授予，同一徽章不重复授予 | `co-reputation/co-reputation-domain/.../BadgePolicy.java` |
| Discovery | Notification | 通知条目 | 一条事件一条通知；已读状态可重置；不重复投递 | `co-discovery/co-discovery-domain/.../Notification.java` |
| Discovery | SearchQuery | 检索词集合 | 词项非空；空词不触发检索 | `co-discovery/co-discovery-domain/.../search/SearchQuery.java` |

## 聚合边界规则

- 跨聚合只通过领域事件或公开 API 通信，不直接持有对方内部对象；
- 一个事务只修改一个聚合；
- 聚合间引用使用 ID，不用对象导航。
