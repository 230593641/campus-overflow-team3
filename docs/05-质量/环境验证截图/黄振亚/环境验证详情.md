# 黄振亚的环境验证详情（DV1）

**结论：环境判定通过。** 实测失败数 **38**，与基线完全一致，且 38 个失败 100% 来自
`UnsupportedOperationException: TODO(S2/S3)：xxx 尚未实现`，无一是环境或依赖问题。

### 执行命令

```bash
git clone https://github.com/230593641/campus-overflow-team3.git
cd campus-overflow-team3/backend
mvn -B -Dmaven.test.failure.ignore=true test
```

> ⚠️ **不要用 `-fae` 统计失败数**。`-fae`（fail at end）虽然会继续构建，但失败模块的下游会被
> `SKIPPED`，实测只能数到 **34** 个失败，会误判成"少了 4 个"。
> `-Dmaven.test.failure.ignore=true` 才能跑完全部模块并拿到真实的 38。

### 给团队的建议

1. **统计失败数务必用 surefire 报告口径**，不要数日志里 `[ERROR]` 行——日志行数会重复计。
   本次以 `backend/**/target/surefire-reports/TEST-*.xml` 汇总为准，得出 54/4/34/38。
2. **后端启动验证需要 Docker**，本机没装所以那一栏是"未验证"。建议 SM 在有 Docker 的环境补一次
   `docker compose -f deploy/docker-compose.yml up -d mysql redis` 的验证，或把这一项明确标为"全员待补"。
3. **Identity 与 Shared Kernel 的测试是全绿的**（2 + 9 个用例），说明参考实现可以独立编译与运行，
   这是 S1 扩展 Identity 的前提。
