# 用户故事地图

> 横轴 = 用户活动序列（从左到右的使用旅程）；纵轴 = 故事卡片，最上面一行是 Walking Skeleton（MVP 切片，贯穿主链路）。
> 本图为骨架初稿，团队需导出 PNG 放同目录（`用户故事地图.png`），并在 S0 评审前补充故事卡片。

## 用户活动序列

注册/登录 → 加入课程 → 浏览问题 → 提问 → 回答 → 投票/评论 → 采纳 → 声誉成长 → 搜索/被推荐 → 接收通知

## Walking Skeleton（MVP 切片，必须先打通）

> 注册登录 → 发布问题 → 提交回答 → 采纳回答 → 声誉结算 → 搜索可检索

## 故事卡片（按列分组，每列至少 2 条）

| 活动列 | 故事卡片（用户故事） |
| --- | --- |
| 注册/登录 | 作为学生我想要用学号注册并登录，以便进入平台；作为学生我想要保持登录会话，以便不用反复登录 |
| 加入课程 | 作为学生我想要按课程加入班级，以便只看到本课程问题；作为教师我想要审批加入申请（S1 增量） |
| 浏览问题 | 作为访客我想要按课程筛选问题；作为访客我想要按标签筛选问题；作为访客我想要看热门标签 |
| 提问 | 作为学生我想要发布带标题/正文/标签的问题（S1-001）；作为学生我想要编辑自己的问题；作为学生我想要软删除自己的问题 |
| 回答 | 作为学生我想要提交带代码块的回答（S1-003）；作为学生我想要编辑自己的回答；作为助教我想要背书一次优质回答 |
| 投票/评论 | 作为学生我赞成/反对问题或回答；作为学生我想要改票；作为学生我想要对帖子发澄清评论 |
| 采纳 | 作为提问者我想要采纳某个回答；作为系统采纳后触发声誉结算 |
| 声誉成长 | 作为用户我想要查看我的声誉账本；作为用户我想要获得徽章；作为用户我想发起悬赏 |
| 搜索/推荐 | 作为用户我想要中文全文搜索；作为用户我想看相关问题推荐 |
| 通知 | 作为用户我想收到回答/采纳/@通知；作为用户我想要标记通知已读 |
