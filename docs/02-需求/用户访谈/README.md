# 用户访谈

## 访谈对象要求

- 至少完成 **3 人**访谈，覆盖学生 / 助教 / 教师至少两类；
- 学生不少于 2 人（不同课程、不同年级更佳）；
- 记录人不少于 1 名，PO 牵头。

## 访谈纪律

- 不引导、不推销方案：先听用户怎么解决现状，再问平台期待；
- 记录原话，不改写、不美化；
- 不承诺平台一定会做某功能；
- 访谈结束 48 小时内整理成纪要归档到本目录。

## 命名规则

`访谈-01-学生.md`、`访谈-02-助教.md`、`访谈-03-教师.md`，编号递增。

## 流程

1. 从 [访谈纪要-模板](访谈纪要-模板.md) 复制新文件；
2. 按提纲访谈，补充第 5 个自拟问题；
3. 提炼痛点（带原话证据）与需求线索（映射到 Identity / Q&A / Reputation / Discovery）；
4. 把高频线索回填到 [Product Backlog](Product-Backlog.md)。
