# 产品愿景

## 1. 电梯演讲

对于**在课程学习中遇到技术问题、却找不到本校同路人解答的学生**而言，他们需要**比班级群更可检索、比公开社区更贴近本校课程进度的提问渠道**；CampusOverflow 是一个**校园版问答平台**，它能**把问题、回答、投票与声誉沉淀成可检索的课程知识资产**。不同于通用 Stack Overflow（问题泛化、无课程归属）和班级群（消息淹没、无法沉淀），我们的产品**按课程组织、以声誉激励高质量回答、只服务本校**。

## 2. 三类用户画像（详见 [用户画像](用户画像.md)）

- 学生：提问、回答、积累声誉；
- 助教 / 研究生：背书优质回答、管理课程内容；
- 教师：创建课程、观察答疑情况；
- 管理员（第四类）：平台治理。

## 3. MVP 范围（四大子域各列 3-5 条功能）

### Identity（身份与认证）
- 学生注册、登录、会话管理；
- 课程创建与成员加入；
- 角色（学生 / 助教 / 教师 / 管理员）与权限；
- 个人资料查看（S1 增量：资料编辑、选课审批、成员管理）。

### Q&A（问答核心）
- 发布问题（标题、正文、标签）；
- 提交 / 编辑 / 删除回答；
- 投票（赞成 / 反对、改票增量）；
- 采纳回答；
- 评论与标签筛选浏览。

### Reputation（声誉与激励）
- 声誉账本（投票 / 采纳带来分值，每日上限）；
- 徽章授予；
- 悬赏发起与结算；
- 排行榜；
- 对账（冻结-扣减-退还守恒）。

### Discovery（内容发现）
- 中文全文搜索；
- 相关问题推荐（Jaccard 相似度）；
- @提及解析；
- 通知（回答 / 采纳 / 提及，已读管理）。

## 4. 明确不做什么（范围外清单）

- 实时聊天 / IM 私聊；
- 直播答疑；
- PDF / 课件内嵌分发；
- AI 自动回答；
- 商业广告与流量变现；
- 招聘 / 兼职信息板块。

> 以上需求若未来提出，先进入 Backlog 的 Won't 区，不在本课程周期实现。
