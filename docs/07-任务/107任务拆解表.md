## 为什么需要它

## 三条规则

1. **任务颗粒度规则**：一个任务 = 一个文件 = 一个 PR，PR 行数控制在 400 行以内；如果某文件方法超过 7 个，允许拆成 2 个 PR，但 Issue 仍为一个。
2. **顺序规则**：只做前置任务已完成的 Issue；同一文件不要两人同时改。
3. **完成规则**：验收命令全绿 + 文件内无 `TODO(Sx)` 残留 + PR 通过评审 + 看板移到「已完成」。
